# استبيان تقييم الدورات — معهد العصر

موقع مجاني بالكامل: الصفحات على **GitHub Pages**، والإجابات في **Google Sheets** عبر **Apps Script**.

| الملف | ما هو |
|---|---|
| `index.html` | صفحة الاستبيان للمشاركين |
| `report.html` | التقرير (بكلمة سر) — يُحفظ PDF من زر «حفظ PDF» |
| `invite.html` | بطاقة الدعوة: رمز QR + الرابط، بمقاس منشور أو ستوري |
| `config.js` | الإعدادات: رابط الخادم، رابط الموقع، الاسم الذي يظهر في التقرير |
| `apps-script/Code.gs` | الخادم الذي يُلصق في Google Sheets |
| `assets/logo.png` | ضعي شعار المعهد هنا (PNG شفاف) |

بدون `API_URL` يعمل الموقع في **وضع تجريبي** ببيانات وهمية، لتجربة الشكل قبل الربط.

## الإعداد (مرة واحدة)

### ١. Google Sheets
1. أنشئي جدولاً جديداً في Google Sheets باسم «تقييم دبلوم الاقتصاد الإسلامي».
2. الإضافات ← Apps Script. احذفي المحتوى والصقي محتوى `apps-script/Code.gs`، ثم احفظي.
3. اختاري الدالة `setup` من القائمة واضغطي «تشغيل» ووافقي على الأذونات.
   - ستظهر ورقتا «الدورات» و«الإجابات».
   - كلمة سر التقرير تظهر في «سجل التنفيذ» (Execution log). احتفظي بها.
4. نشر ← نشر جديد ← النوع: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. انسخي رابط Web app وضعيه في `config.js` داخل `API_URL`.

> كل تعديل على `Code.gs` يحتاج: نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد.

### ٢. GitHub Pages
1. ارفعي محتوى المجلد إلى مستودع عام (Public) على GitHub: Add file ← Upload files.
2. Settings ← Pages ← Deploy from a branch ← `main` و`/ (root)` ← Save.
3. الرابط: `https://bahijashekhdeep.github.io/alasr-survey`، وهو مكتوب في `config.js` داخل `SITE_URL`.
4. لكل تعديل: ارفعي الملفات من جديد (Ctrl+A ثم اسحبيها كلها)، ويتحدّث الموقع خلال دقيقة أو دقيقتين.
   - عند تعديل ملفات CSS/JS غيّري `?v=2` في الصفحات إلى رقم أعلى، حتى لا يعرض المتصفح النسخة القديمة.

> Netlify وGitHub الخاص غير متاحين في منطقتنا، لذلك الموقع على GitHub Pages.

### رابط الواتساب
أرسلي `https://bahijashekhdeep.github.io/alasr-survey/?s=1`، وانتظري ثواني حتى تظهر صورة «قيّم الدورة» قبل الإرسال. الضغط على الصورة يفتح التقييم.

## الاستخدام كل أسبوع
1. في ورقة «الدورات» أضيفي سطراً للدورة الجديدة، واكتبي «نعم» في عمود «فعّالة» لها فقط (وامسحيها من الدورة السابقة).
2. افتحي `invite.html` ونزّلي البطاقة، وأرسليها مع الرابط.
3. بعد انتهاء التقييم افتحي `report.html`، واختاري الدورة، ثم «حفظ PDF».
   - في نافذة الطباعة: الوجهة **Save as PDF**، والهوامش **Default**، و**ألغي** «Headers and footers»، و**فعّلي** «Background graphics».
4. عند وجود دورتين أو أكثر يظهر خيار «التقرير الشامل للدبلوم».

## ⚠️ تنبيه مهم: تغيير الأسئلة
- لا تزيدي أو تحذفي أسئلة التقييم بعد وصول إجابات، لأن أعمدة جدول «الإجابات» ستختلط.
- غيّري الأسئلة **بين دبلوم ودبلوم فقط**: انسخي الجدول القديم واحتفظي به، ثم ابدئي جدولاً جديداً للدبلوم الجديد.
- تعديل نص السؤال (الصياغة فقط) آمن في أي وقت.
